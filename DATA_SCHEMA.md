# Data schema (v1.0)

The interface never contains news. It reads three kinds of JSON file:

| File | Purpose |
|---|---|
| `data/site.json` | Name, timezone, section list, homepage order, verification labels |
| `data/editions.json` | Manifest of all editions (generated by `scripts/build_manifest.py`) |
| `data/editions/YYYY-MM-DD.json` | One file per edition: articles + watchlist |

## Edition

| Field | Type | Notes |
|---|---|---|
| `schema_version` | string | `"1.0"` |
| `edition_number` | integer | Shown as "No. 47" |
| `date` | `YYYY-MM-DD` | Must match the filename |
| `published_at` | ISO 8601 with offset | When the edition goes live |
| `status` | `draft` \| `scheduled` \| `published` | Drafts never show. Scheduled editions show once `published_at` has passed |
| `is_demo` | boolean | Shows the demonstration banner |
| `editor_note` | string | Optional note under the masthead |
| `articles` | Article[] | Any order |
| `watchlist` | WatchItem[] | Tomorrow's events |

## Article

| Field | Required | Notes |
|---|---|---|
| `id` | yes | Unique and stable, e.g. `2026-10-11-deals-01` or a hash of the source URL |
| `section` | yes | A `slug` from `site.json` (`india`, `markets`, `deals`, `corporate`, `geopolitics`, `tech`, `climate`, `analysis`, `learn`) |
| `category` | yes | Short label shown as the kicker, e.g. "M&A", "IPOs" |
| `front_page_rank` | no | 1–5 places the story on the front page (1 = lead). `null` otherwise |
| `headline` | yes | |
| `dek` | no | One-line standfirst |
| `summary` | yes | 1–3 sentences, shown on cards |
| `body` | no | Array of blocks: a plain string (paragraph), `{type:"h2",text}`, `{type:"quote",text,cite}`, `{type:"list",items:[]}` |
| `why_it_matters` | yes | Shown on cards and as a callout on the article page |
| `implications` | no | `[{label, text}]`, e.g. "For lenders" |
| `key_figures` | no | `[{label, value}]`, shown as a figures strip |
| `key_takeaways` | no | Array of strings (used by Learn Something New) |
| `author` | no | Byline |
| `published_at` / `updated_at` | yes / no | ISO 8601 with offset |
| `source` | yes | `{name, url, published_at, type}`; `type` is `rss`, `api`, `manual` or `demo` |
| `verification` | yes | `{status, checked_by, checked_at, notes}` |
| `tags` | no | Used by search |
| `is_demo` | yes | `true` for fictional stories |
| `pipeline` | no | `{feed_id, ingested_at, summarised_by, summary_model}` for audit |

### Verification statuses

| Status | Meaning |
|---|---|
| `demo` | Fictional demonstration content |
| `unverified` | Ingested automatically, not yet checked |
| `source-linked` | Summary checked against the linked original |
| `verified` | Checked by an editor against primary sources |
| `corrected` | Changed after publication; explain in `notes` |
| `evergreen` | Explainer that does not report news |

## WatchItem

`{id, date, time, timezone, title, category, region, importance (high|medium|low), description, source:{name,url}, verification:{status,notes}, is_demo}`
